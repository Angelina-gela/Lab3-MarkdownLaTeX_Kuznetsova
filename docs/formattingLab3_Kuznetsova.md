# Задание: Комментирование программа на С#
Создайте консольное приложение на С#, которое демонстрирует все форматы Markdown в комментариях к коду.
### Требования к программе: 
1. **Имя файла:** `FormatDemo.cs`
2. **Логика:**
    - Запрашивает у пользователей **два числа**
    - Выполняет **их сложение**
    - Выводит результаты в **форматированном виде**
***
### Пример структуры кода с комментариями в стиле Markdown:
```csharp
Console.Write("Введите первое число:");
double number1 = Convert.ToDouble(Console.ReaLine());
Console.Write("Введите второе число:");
double number2 = Convert.ToDouble(Console.ReaLine());
double sum = number1 + number2;
Console.WriteLine($"**Результаты операций: {sum}**");
