## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Что такое Markdown
Markdown — это лёгкий язык разметки для оформления текста.

#### Где он применяется
Используется в README, документации, блогах, GitHub, VS Code, заметках.

#### Зачем он нужен разработчикам
Позволяет быстро писать читаемую документацию без сложных редакторов.
