## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Markdown — это облегчённый язык разметки, созданный в 2004 году Джоном Грубером и Аароном Шварцем для простого форматирования текстов с помощью обычных символов с клавиатуры.

#### Markdown находит широкое применение в различных сферах:
Веб-разработка
Блоги и платформы для написания
Электронные письма и форумы
Статические сайты
Документация 
Системы управления версиями
Примечания и заметки
Презентации

#### Разработка Markdown нужен для быстрого и простого написания документации, README-файлов, заметок, комментариев и сообщений, которые легко читать и форматировать в простом тексте, а затем преобразовывать в HTML, PDF или другие форматы без сложных редакторов. Он экономит время, повышает читабельность и обеспечивает единообразное.
